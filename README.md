# Макети головної SAINTIS

Тільки відрендерені сторінки. Вихідники, брифи, розшифровки дзвінків
і супровідні документи лишаються в приватному репозиторії `SAINTIS`
і сюди не потрапляють.

Сторінка вибору для замовниці: <https://ynkotp-webdev.github.io/variants/>

| Адреса | Макет |
| --- | --- |
| `/variants/` | сторінка вибору напрямку |
| `/v3/` | «Класика» |
| `/v6/` | «Схема» |
| `/v10/` | «Горизонт» |

Корінь віддає редирект на `/variants/`. Усі сторінки під `noindex`,
плюс `robots.txt` із `Disallow: /`: це матеріал для узгодження,
а не бойовий сайт.

Папка збирається скриптом `tools/publish-pages.py` із приватного
репозиторію після `npm run build`. Руками тут нічого не правиться.
